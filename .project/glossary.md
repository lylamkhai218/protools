# PROJECT GLOSSARY & TERMINOLOGY (THUẬT NGỮ CHUẨN)

| Thuật ngữ | Định nghĩa / Ý nghĩa kỹ thuật |
| :--- | :--- |
| **RFQ (Request for Quote)** | Yêu cầu báo giá: Quy trình người mua B2B chọn danh mục sản phẩm và gửi thông số để nhận báo giá chiết khấu dự án từ T&T Vina. |
| **Spec-sheet (Specification Sheet)** | Bảng dữ liệu thông số kỹ thuật chi tiết của thiết bị cơ khí (kích thước, độ dày, vật liệu phủ, tốc độ cắt, dung sai). |
| **Industrial Precision** | Phong cách thiết kế công nghiệp tập trung vào độ chính xác, độ tương phản cao, tối ưu cho kỹ sư và nhà thu mua. |
| **Container Queries** | Kỹ thuật CSS hiện đại giúp component tự co giãn hiển thị dựa trên kích thước của container chứa nó thay vì toàn bộ màn hình. |
| **Touch Target 48px** | Chuẩn kích thước vùng bấm tối thiểu (48x48 pixel) để kỹ sư có thể thao tác chính xác bằng màn hình cảm ứng khi đeo găng tay. |
| **dvh (Dynamic Viewport Height)** | Đơn vị CSS Viewport động giúp thanh CTA không bị che khuất bởi thanh công cụ trình duyệt di động (Safari/Chrome). |
| **Imunify360 (IM360 WAF)** | Hệ thống tường lửa bảo mật máy chủ Mắt Bão, tự động chặn IP khi phát hiện dấu hiệu SQL Injection hoặc HTTP bridge script. |
| **Auto-Ban TTL** | Thời gian máy chủ tạm khóa IP vi phạm WAF (thường từ 15 - 30 phút). |
| **Traceability** | Khả năng truy xuất nguồn gốc hai chiều từ Mục tiêu kinh doanh (`BUS`) đến Yêu cầu (`FR`), Thiết kế (`SAD`), Task, Code và Test. |
| **ADR (Architecture Decision Record)** | Bản ghi quyết định kiến trúc phần mềm, ghi lại bối cảnh, lý do, hệ quả và đánh giá rủi ro của quyết định. |
